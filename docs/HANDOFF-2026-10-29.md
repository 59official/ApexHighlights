## 改了哪些文件（`src/ApexHighlights/`）

- **`ClipKinds.cs`**：新增 `public static readonly ClipKind[] All`（Knock, ReKnock, AssistKnock, Elim, AssistElim），注释写明「Kill/Knocked 是死值」。这是菜单顺序、筛选器索引、开关列表的唯一来源。
- **`ClipQuery.cs`**：`KindByIndex(int)` 从 switch 改成 `index >= 1 && index <= ClipKinds.All.Length ? ClipKinds.All[index - 1] : null`，越界返回 null。
- **`LibraryForm.cs`**：种类下拉由 `ClipKinds.All` 生成（「全部种类」+ 5 项）；悬停提示同样按表拼，不再写死「击杀 / 被击倒」。
- **`CapturePolicy.cs`**：新增 `List<ClipKind> SkipKinds`（JSON 里写 enum 名字，`JsonStringEnumConverter`）、`Records(ClipKind)`、`SetRecords(ClipKind, bool)`；`Clamp` 去重并丢掉本版本已不存在的种类；`Save` 只多写 `SkipKinds` 一个字段。
- **`Capture.cs`**：新增 `Func<ClipKind, bool>? KindFilter` + `private bool Records(ClipKind)` + `public bool WillRecord(ClipKind)`（自检要看闸门状态）。两处落盘前加闸门：`ClipLoop()`（主路径，`continue` 等下一场）和 `FlushPending()`（退出补切，否则关程序那一刻会漏一段）。注意 `Detection.Kind` 是 `BannerKind`，闸门前必须 `ClipKinds.FromBanner(...)` 转成 `ClipKind` —— 未识别横幅会落到「击倒」，不转就和用户勾的「击倒」对不上。
- **`TrayApp.cs`**：`BuildKindsMenu()` / `ApplyKind()`（照 `BuildBitrateMenu()`/`ApplyBitrate()` 的形状；勾选项用 `CheckOnClick`，标题实时显示「已关：助攻击倒」/「全关了：不录任何片段」）；`StartCapture()` 里 `_cap.KindFilter = k => _capture.Records(k)` —— 闭包抓着同一个 `CapturePolicy` 实例，所以托盘里改了立刻生效，不用回头动 `_cap`；自检钩子 `FindKindsRoot/ClickKind`，`ArmSelfTest()` case 3 增加「关掉助攻击倒 → 看到闸门 False → 开回来」。
- **`PillSelect.cs`**：`ShowMenu()` 变开关；新增 `_menu`/`_menuSettled`/`_dismiss` 字段、`CloseAnimated()`、`Dismiss(filter)`、内嵌 `DismissFilter : IMessageFilter`（只认按下消息，认松开会把拖选文字也误关）、`internal bool IsOpen`；`WatchLeave()` 的收起逻辑改成调 `CloseAnimated()`，不再自己拼一遍动画；Esc 自己处理（`AutoClose=false` 时窗口不会替我们关）。
- **`UiTest.cs`**：`FilterChecks` 改成按 `ClipKinds.All` 遍历（原来写死 1..7，含 6/7 两个已删索引，改完会 NullReference）；新增 `PillToggleCheck()`：真开一个离屏窗口 → 点一下弹出 → 再点一下必须只收不弹 → 泵消息等动画跑完确认菜单关掉、`IsOpen=false`。
- **`Program.cs`**：`--lib-ui --shot-menu=` 支持字段是 Panel 的情况（`_kindPill` 是包着 `PillSelect` 的 Panel），往下找第一个 `PillSelect` 孩子，否则种类下拉截不到图。
- **`CapturePolicy.ApplyBitrate` 的坑（TrayApp.cs）**：原来 `CapturePolicy.Clamp(new CapturePolicy { ... })` 新建对象，`SkipKinds` 会被悄悄清空 —— 已改成直接在 `_capture` 上 `Math.Clamp` 赋值。
