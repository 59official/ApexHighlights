## 2026-10-28 待确认事项已定：回顾库 UI 形态

**决定：WinForms 托盘应用。**

不选本地网页的原因：要起端口、要浏览器、还要维护前端构建，跟"轻量化"直接冲突，用户明确要的是开机即用、不占资源。

不选纯命令行的原因：回顾、剪辑、导出这些操作要翻素材，纯命令行体验太差，普通用户不会用。

WinForms 托盘的理由：随 .NET 运行时走，无额外依赖，托盘常驻内存低，跟已有的 C# 技术栈一致。
