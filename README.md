# ApexHighlights

Apex Legends 自动集锦录制器：常驻环形缓冲，检测到屏幕中间的击倒横幅后，自动把**前 15 秒**回取出来落盘成带音频的 mp4。

不注入、不读内存、不装驱动、不模拟输入、不联网。单 exe 目录、无账号、无服务器。

> 状态：采集 / 编码 / 音频 / 切片 / 配额清理 / 回顾库 / 托盘常驻 / 安装包 都已实测跑通（2560×1440 60fps、双轨成片、HEVC 与 H.264 双编码）。技术细节见 [docs/apex-v1-spec.md](docs/apex-v1-spec.md) 与 [docs/DECISIONS.md](docs/DECISIONS.md)。

## 为什么不用 OBS

OBS 也能做，代价是：GPL 传染（写插件 = 衍生作品）、要先装 300MB 的 OBS、以及同一场交火的两次击倒会产出两份重叠视频。自研环形缓冲能把它们合并成一条文件，并且全程 GPU 不落 CPU。

## 它是怎么工作的

```
WGC 抓窗口 → GPU 转 NV12 → NVENC/MFT 编码 → 1s fMP4 分片环（内存/磁盘）
                              ↘ 10fps 采条带 → 高通 + NCC 匹配横幅 → 命中
WASAPI（进程回环 / 整机回环 / 麦克风）→ 混音 → AAC 160kbps → 内存音频环
                                                    ↓
                              按前摇回取 → 音视频对齐 → 单文件双轨 mp4
```

- **GPU 全程不落 CPU**：采集帧是 D3D11 纹理，直接喂给硬件编码器（`MFCreateSample` + `MFCreateDXGISurfaceBuffer`），CPU 只做 10fps 的条带读回用于检测。
- **检测很便宜**：条带 1280×120，高通 + 归一化互相关，单次 1–2ms；命中之后才做 OCR。
- **音视频共用同一个 `Stopwatch` 时间轴**，切片时按第一帧视频的绝对时间对齐两条轨。
- **不用 ffmpeg**：mp4 封装自己写（`Mp4.cs` / `Mp4Writer.cs`），直接装 `hvc1`/`avc1` + `mp4a` 两轨。

## 下载与安装

两种都行，功能一样：

- **安装包**（推荐）：`ApexHighlights-<版本>-setup.exe`。装到 `%LOCALAPPDATA%\Programs\ApexHighlights`，带开始菜单项、可选开机自启、可正常卸载。安装过程会弹一次 UAC——那是为了注册「身份包」关掉 Windows 11 的录制黄框；点「否」也能装完，只是黄框留着。
- **便携版**：`ApexHighlights-<版本>-portable.zip`，解压即用，配置写在 exe 旁边。

自带 .NET 运行时，目标机器不需要装任何东西。首次启动会在数据目录建出 `captures/`、`games/`、`config.json`（内嵌默认配置会释放出来，之后可以就地改）。想清空就删掉整个目录。

exe 放在 Program Files 之类只读位置时会自动改用 `%LOCALAPPDATA%\ApexHighlights`，也可以用 `--data=<目录>` 显式指定。

### 系统要求

| 能力 | 最低系统 |
|---|---|
| 录制 + 音频（含「只录游戏」的进程回环） | Windows 10 2004（10.0.19041） |
| 关掉录制黄框（`IsBorderRequired`） | Windows 11 22H2+，且用安装包装、并同意注册身份包 |
| 硬件编码 | 任意支持 NVENC / QuickSync / VCE 的显卡；没有 HEVC 编码器时自动退回 H.264 |

黄框是 Windows 的采集提示（不是本程序画的），Windows 10 上没有任何办法关掉，但它**不会出现在录像里**（WGC 只抓窗口内容）。

## 跑起来

```
# 托盘常驻（双击 exe 或 run-live.bat）
ApexHighlights.exe

# 前台跑，指定窗口标题（开发时用任意动画窗口测试）
ApexHighlights.exe --title="BenchWnd" --fps=60 --bitrate=30 --duration=30 --fake-hit=12
```

| 参数 | 说明 |
|---|---|
| `--data=<目录>` | 数据目录（captures / games / config.json 都在这下面） |
| `--title=<片段>` | 窗口标题子串；`self` 表示自己的控制台窗口 |
| `--fps=<n>` | 目标帧率，默认 60（30/60/120） |
| `--bitrate=<n>` | 码率 Mbps；不给就用 `config.json` 的 `BitrateMbps`（默认 30） |
| `--gop=<n>` | GOP 帧数，默认等于 fps |
| `--duration=<n>` | 跑 n 秒后退出（不填则一直跑） |
| `--fake-hit=<n>` | 第 n 秒伪造一次命中，用于端到端验证 |
| `--no-audio` | 整段关掉音轨（等于把音源设成「关」） |
| `--no-beep` | 关掉录制提示（等于「录制提示」选「关」） |
| `--no-tray` | 不常驻托盘，纯控制台 |
| `--ui` | 启动时先把回顾库窗口打开 |
| `--config=<路径>` | 配置文件，默认数据目录下 `config.json` |
| `--log=<路径>` | 诊断日志（会归档上一份）；托盘模式下默认写数据目录的 `live.log` |

## 录制参数（托盘 →「录制参数…」，或回顾库工具条）

| 项 | 范围 | 默认 | 作用 |
|---|---|---|---|
| 比特率 | 4–60 Mbps | 30 | 越大越清楚、体积越大 |
| 击杀前 | 0–30 s | 15 | 命中前回取多久（`0s` = 事件发生前无录制） |
| 击杀后 | 0–30 s | 15 | 命中后继续录多久（`0s` = 事件后立即结束） |
| 合并窗口 | 0–30 s | 8 | 多近的两次命中算同一场交火（`0s` = 每次命中各出一段） |
| 视频编码 | H.264 / HEVC | **HEVC** | 见下 |

拖动即时生效，松手就写盘，没有「保存」按钮；底部「恢复默认」= 30 / 15 / 15 / 8 / HEVC。

**关于 HEVC**：同码率比 H.264 干净，同画质体积小 30–50%；代价是 Windows 自带播放器需要装「HEVC 视频扩展」（或者用 VLC / PotPlayer / mpv 这类自带解码的播放器）。机器没有 HEVC 编码器时会自动退回 H.264 并在日志里说明；换编码会让录制重开一次（分片不能一半一种编码）。

## 音轨四档（托盘 →「音轨」）

| 档位 | 录什么 | 说明 |
|---|---|---|
| 只录游戏（推荐，默认） | 游戏进程自己的声音 | 用进程回环，别人开黑、放歌都不会混进来 |
| 系统声音 + 麦克风 | 整机混音 + 你的麦克风 | 想留自己指挥的声音选这个 |
| 系统声音 | 整机混音 | 桌面里的一切声音 |
| 关 | 不录 | 需要纯画面素材时用 |

麦克风会重采样后混进同一条轨（不会单独出第二轨）。

## 录制提示（托盘 →「录制提示」）

- **滑出浮层**（默认）：右上角滑出一张 320×72 的卡片，1s 滑入、1.5s 停留、0.5s 收起；开始录和落盘各一次。
- **提示音**：只在落盘时「叮」一声。
- **关**：什么都不弹。

浮层是独立窗口，不在录像里；提示音走播放设备，进程回环模式下不会被录进片段。

## 回顾库

托盘右键 →「打开回顾库」。左侧列表、右侧详情（缩略图 + 元数据），顶部可按种类 / 时间 / 文件名筛选。

- **播放 / 打开目录 / 选择目录 / 删除 / 录制参数**——`选择目录` 能把成片改到别的盘（会问要不要把已有片段搬过去）。
- **批量删除**：点 `删除` 进入批量态，每行前面出现圆角勾选框，表头「全选」一次全勾，`删除选中（N）` 一次删干净。
- **配额与保留**：点状态栏右下角的「配额 40GB · 保留 30 天」直接改档。
- **F5** 刷新，**Enter** 播放，**Delete** 删除。

## 配额与保留期

默认 **40GB / 保留 30 天 / 2GB 磁盘水位 / 每小时检查**，写在 `config.json`：

```json
{ "QuotaGb": 40, "RetainDays": 30, "WatermarkGb": 2, "CheckMinutes": 60 }
```

- `QuotaGb: 0` = 不限体积；`RetainDays: 0` = 永久保留；`WatermarkGb: 0` = 不检查磁盘。
- 超保留期的直接删；还超配额时按**被击倒 > 击倒 > 击杀**淘汰，同优先级内从旧到新。
- 磁盘跌破水位时暂停往环形写新数据，已录好的片段照常落盘。
- 检查时机：启动时、每片落盘后、每小时。

片段就是文件名本身，没有数据库：`apex_1028-130333_0.99.mp4`。想手动归档直接挪文件即可。

## 横幅识别

命中靠「横幅锚点图」做归一化互相关，内置英文 / 简体中文 / 繁体中文三张模板（阈值 0.60），三张一起取最高分——**游戏用哪种语言都能认**。

分类（击倒 / 再次击倒 / 助攻击倒 / 小队淘汰 / 助攻淘汰）用 Windows 自带 OCR 读横幅文案，中英通吃；没装对应语言包时自动降级成「击倒」，但仍照常录像。

两个常见疑问：

- **分辨率不同不影响**：条带在采集时统一缩放回 2560×1440 基准空间，900p / 1080p / 1440p / 2160p 实测都过阈值。
- **游戏内 HUD 缩放会影响**：互相关对尺度很敏感（±10% 就从 0.99 掉到 0.4）。托盘的「HUD 缩放」可以手动选 80/90/100/110/120%，默认「自动」——只有分数落进灰区才多扫几档，平时零开销。

## 自检命令

不依赖真实游戏，任何一条都能单独跑（打印 `ok` / `NG`，返回码非 0 表示有失败）：

| 命令 | 验证什么 |
|---|---|
| `--gpu-test [--codec=hevc]` | GPU 直通编码全链路（NV12 转换、码率、分片、MF 回读） |
| `--av-test` | 双轨封装（合成正弦 + 渐变画面 → 音视频各一轨的 mp4） |
| `--mp4-check <mp4> [--decode]` | MF 回读两条流的样本数/末时间戳；加 `--decode` 再真解一帧出来 |
| `--audio-check <mp4>` | 把成片音轨解回 PCM 量峰值（双轨存在 ≠ 有声音） |
| `--audio-test --sec=3` | WASAPI 采音（设备、混音格式、有效采样率、峰值） |
| `--audio-probe[=ms]` / `--audio-probe-sta` | 进程回环能否取到包（MTA / STA 各一遍） |
| `--mic-test` | 麦克风重采样 + 混音数学（合成波形） |
| `--ocr-parse-test` | 横幅文案分类（中/英/繁 19 条断言） |
| `--ocr-langs` | 列出系统已装的 OCR 语言包 |
| `--band-check --dir=<目录> [--hud=110]` | 阈值回归：把历史 `hit_*.bmp` / `near_*.bmp` 重跑检测器 |
| `--band-tool=<截图.png> [--game=apex]` | 条带标定器：在截图上拖框，生成 `band` 的 JSON、把框里那截存成模板 PNG |
| `--make-cover=<封面.png> [--cover-size=1920x1080]` | 出视频封面（程序图标 ≈ 击倒骷髅），纯代码绘制，改配色/尺寸重新跑一遍即可 |
| `--ocr-check --dir=<目录>` | 横幅分类回归：重跑 OCR 列出识别结果 |
| `--policy-test` | `config.json` 读写：默认值、老配置迁移、只写自己的字段 |
| `--quota-test` | 配额/保留期逻辑（临时目录伪造片段，不碰真实库） |
| `--ui-test [--dir=<片段目录>]` | 界面层：列表、筛选、批量勾选、配额菜单、参数面板 |
| `--tray-test=N` | 托盘自检：菜单、状态行、暂停、开库、改阈值、退出 |
| `--lib-ui --shot=<png>` / `--shot-params=<png>` | 截界面图（改外观时用） |

## 构建

需要 .NET 8 SDK 和 Windows 10 19041+：

```
dotnet build -c Release src/ApexHighlights/ApexHighlights.csproj
```

依赖 `Vortice.Direct3D11` / `Vortice.MediaFoundation`（NuGet 自动拉取）。

出可分发的自包含版本（约 73MB zip，自带运行时）：

```
dotnet publish src/ApexHighlights/ApexHighlights.csproj -c Release \
  -r win-x64 --self-contained true -p:PublishSingleFile=false -p:DebugType=none -o dist
```

产物是 `dist/ApexHighlights.exe` 加一批 dll，整个 `dist/` 拷走即可。

> **为什么不用 `PublishSingleFile`**：单文件包把原生库嵌进 exe，每次启动要先解压到 `%TEMP%\.net\...`。部分机器上这一步会被拒（`Failed to create directory ... for extracting bundled files`），exe 直接起不来。文件夹版没有这个坑。

一键出安装包 + 便携包：`packaging/pack-release.sh`（需要 `.tools/dotnet` 与 `.tools/inno setup` 的 `ISCC.exe`，见脚本头部说明）。

## 已知限制

- 独占全屏可能抓不到（WGC 依赖 DWM 合成），全屏请用「无边框窗口」。
- 相邻命中 ≤ 合并窗口视为同一场交火，只出一段；所以片段在**末次命中后约 8 秒**才出现。
- 大厅开始录、进了对局才窗口变尺寸时，采集会自动重开一次，中间那一小段帧补不回来。
- 自定义游戏要自己填 `games/<id>.json` 的条带位置：用 `--band-tool=<截图.png>` 拖个框就能生成（见下）。分辨率不用重标——`band` 是「基准分辨率」坐标系里的数，采集时按实际画面尺寸等比例缩放。
